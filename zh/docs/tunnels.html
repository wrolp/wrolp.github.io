用户手册/第 6 章

支持的范围

本地端口转发规则按连接保存。可以在侧栏中添加、编辑、删除、启动 和停止。由于隧道由 SSH 会话本身承载，它们复用与终端相同的 russh 通道。

状态同步

当隧道状态变化时，后端会发出 tunnel-changed，使界面反映实际状态， 而不是本地推测。

未确认。 源材料只描述了本地转发。它没有记录远程 转发（-R）、动态 SOCKS 转发（-D）、绑定地址字段、首选本地端口， 也没有说明连接打开时规则是否自动启动。添加/编辑对话框的字段与默认值同样未记录。

使用隧道

已确认的工作流仅限于 README 所述内容：为某个连接创建本地转发规则，然后 在侧栏启动或停止它，并确认状态变更已由后端传播过来。

操作提示。 隧道依附于拥有它的 SSH 会话，因此会话关闭也可能导致隧道停止； 文档中记录的 connection-closed 状态是标签上需要留意的信号。
