用户手册/第 3 章

标签

连接会作为标签打开在多标签终端区域中。每个标签都有自己的状态指示（见第 2 章）， 并且可以在不新开第二个会话的情况下重连。

分割树与浮动面板

  • 终端区域采用分割树布局：面板可以水平或垂直分割，叶子节点承载 终端、Docker 日志或编辑器。
  • 任何面板都可以弹出为独立的浮动窗口。
  • 打开的文件与日志按会话隔离，因此一个连接的编辑器或日志视图不会 渗透到另一个连接中。
  • 本地 shell 与远程 shell 可以并排使用，因为两者都使用同一套 RemoteFs 抽象。
未确认。 分割面板的确切命令或拖拽目标，以及布局是否在重启后恢复， 源材料中均未描述。窗口几何尺寸与不透明度会被持久化，但这本身并不 能确认标签或分割布局的持久化。

快捷键

所有快捷键都集中在 src/lib/keybindings.ts 的一张表中。设置中允许重新绑定单个 条目、重置单个条目，或重置全部。

保留键不可绑定：Tab、Enter、Ctrl+C、Ctrl+V、Ctrl+X、Ctrl+Z、Ctrl+D、Ctrl+W。

未确认。 README 没有列出默认快捷键分配，因此这里不复制默认键位表。 请从你正在运行的构建中读取 src/lib/keybindings.ts 里的表以获得准确内容。

窗口与应用行为

  • 自定义标题栏。
  • 窗口几何尺寸与不透明度在多次运行之间持久化。
  • 单实例保护：再次启动应用不会创建第二个实例。
  • 中文和英文字符串；语言默认跟随系统语言。

更新

应用包含一个自动更新器，指向 GitHub Release 端点。它要求 在 tauri.conf.json 中配置真实的 pubkey；缺少该密钥时，你自己构建的版本无法更新。
