用户手册/第 3 章

标签

连接会作为标签打开在多标签终端区域中。每个标签都有自己的状态指示（见第 2 章）， 并且可以在不新开第二个会话的情况下重连。

分割树与浮动面板

  • 终端区域采用分割树布局：面板可以水平或垂直分割，叶子节点承载 终端、Docker 日志或编辑器。
  • 任何面板都可以弹出为独立的浮动窗口。
  • 打开的文件与日志按会话隔离，因此一个连接的编辑器或日志视图不会 渗透到另一个连接中。
  • 本地 shell 与远程 shell 可以并排使用，因为两者都使用同一套 RemoteFs 抽象。

快捷键

所有快捷键都集中在 src/lib/keybindings.ts 的一张表中，设置里可逐项重新绑定、重置单项或全部重置。 组合键按精确匹配生效，例如 Ctrl+B 不会在 Ctrl+Alt+B 上触发。macOS 上 Ctrl 对应 Cmd。

操作默认快捷键
命令面板Ctrl+K
显示或隐藏侧栏Ctrl+B
把侧栏换到另一边Ctrl+Alt+B
显示或隐藏下栏Ctrl+J
在下栏与右栏之间切换面板位置Ctrl+Alt+J
显示或隐藏检视器Ctrl+Alt+I
分屏终端Ctrl+\
命令片段列表Ctrl+Shift+P
命令历史Ctrl+Shift+H
双栏文件视图Ctrl+Shift+F
命令补全列表Alt+/
向上 / 向下翻一页Shift+PgUp / Shift+PgDn
跳到最早的输出 / 跳回提示符Shift+Home / Shift+End

关闭浮层Esc

保留键不可绑定：Tab、Enter、Space、Backspace、Delete，以及 Ctrl+C、Ctrl+V、Ctrl+X、Ctrl+Z、Ctrl+D、Ctrl+W、Alt+Tab、Ctrl+Shift+Esc。

窗口与应用行为

  • 自定义标题栏。
  • 窗口几何尺寸与不透明度在多次运行之间持久化。
  • 单实例保护：再次启动应用不会创建第二个实例。
  • 中文和英文字符串；语言默认跟随系统语言。

更新

应用内置自动更新器：从 GitHub Release 的 latest.json 检查更新， 用 tauri.conf.json 中的 pubkey 校验安装包，并以 passive 模式启动安装。
