支持的平台

Windows 是主要目标平台，也是唯一发布了安装包的平台。项目同样可以在 Linux 和 macOS 上运行与开发， 但这些平台需要从源码构建。

平台已发布的安装包源码构建
WindowsMSI支持
Linux无支持；需要下文列出的 Debian/Ubuntu 包
macOS无支持；无需额外系统依赖
为什么只有 MSI。 tauri.conf.json 中的打包目标为 ["msi"]，因此 发布流程不会发布其他安装包格式。

安装 Windows 版本

当前版本为 v0.0.12（2026-11-07）。请从 GitHub Releases 页面下载 MSI，双击运行并按安装向导完成安装。 安装包只包含 Windows 目标，安装后可从开始菜单或桌面快捷方式启动。

构建要求

Linux 系统包（Debian/Ubuntu）

sudo apt-get install -y pkg-config libdbus-1-dev libssl-dev libgtk-3-dev \
  libjavascriptcoregtk-4.1-dev libsoup-3.0-dev libwebkit2gtk-4.1-dev

macOS 和 Windows 无需额外的系统依赖。

工具链

  • Rust，通过 rustup 安装。
  • 前端依赖使用 yarn 安装。
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
yarn

构建、运行与测试

yarn tauri dev      # 完整栈（Tauri 会自动启动 Vite 开发服务器）
yarn dev            # 仅前端，用于纯 UI 调试（不含 Rust/SSH）
yarn build:clean    # 发布构建，输出到 src-tauri/target-release/release/bundle/
yarn tauri build    # 增量构建，输出到 src-tauri/target/
cd src-tauri && cargo check && cargo clippy && cargo test
cd src-tauri && cargo run --bin ssh_test   # 独立的 russh 连通性探测
npx playwright install && yarn test:e2e    # 前端 E2E，使用打桩的 Tauri IPC

E2E 测试套件位于 e2e/ui/，包含约 100 个用例。由于后端通过 window.__TAURI_INTERNALS__ 打桩，Playwright 运行不需要 Rust 构建。

发布

gh auth login -h github.com
yarn run publish    # 先构建，然后上传到 GitHub Release

设置 RELEASE_SKIP_CLEAN=1 可复用已有的构建产物，而不先清理。发布后可用 yarn gen:latest 生成更新清单 latest.json；自动更新器从 releases/latest/download/latest.json 读取版本，并用 tauri.conf.json 中的 pubkey 校验安装包。
