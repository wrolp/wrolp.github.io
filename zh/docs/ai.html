用户手册/第 10 章

两种模式

  • Chat — 非流式，实现为 ai_chat_sync。
  • Agent — 带工具调用的流式模式，实现为 run_agent_stream。在 Agent 模式下， 助手可以在已连接的服务器上调用工具。

两种相互隔离的聊天

  • 检查器侧栏中的应用级聊天：它不属于任何终端，后端会拒绝它的所有 shell 工具。
  • 停靠在每个分栏中的终端绑定聊天：它可以执行 run_command、读取文件，并 「发送到终端」。

这一划分是主要的安全边界：只有附加到终端的会话才能对该主机执行操作。

端点配置

可以保存多个 AiEndpointProfile 条目，每个条目各自拥有：

  • API 密钥（加密存储）
  • 端点 URL
  • 模型名称
  • 系统提示词

可用模型可以从 {endpoint}/v1/models 拉取。

API 密钥存储

密钥使用 AES-256-GCM 文件保险库加密。密钥文件 vault.key 与当前机器绑定， 不使用操作系统钥匙串。

使用助手

  • 图片：将图片附加到消息，或直接粘贴；点击缩略图可打开完整图片。
  • 模板：模板下拉菜单可插入提示词。
  • 重发：编辑任意历史消息并再次发送。
  • 取消：cancel_ai_chat 中止正在进行的生成。
  • 发送到终端：代码块或选中文本会按连接类型（SSH、本地 shell、串口或 Telnet）插入目标 分栏。仅插入，不执行任何内容。
运行前审阅。仅插入的行为是刻意设计的：你可以在终端提示符处检查生成的命令，然后自己按 Enter。
