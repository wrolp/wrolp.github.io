用户手册/第 4 章

远程文件浏览

  • 远程文件树，支持目录列出、读取、写入、重命名、删除和创建目录操作。
  • 通过 SFTP（russh-sftp）上传和下载，复用与终端相同的 SSH 会话通道。
  • 本地与远程浏览共用 RemoteFs 抽象，因此本地与远程面板行为一致。

传输队列

每个排队文件占一行，显示已完成字节数与总量，以及实时传输速度。

  • 目录与拖放上传在 Rust 侧用 walkdir 一次性遍历。
  • 进度以 4 MiB 分块上报；单文件上传使用 64 KB 分块。
  • 进度通过 transfer-progress 事件送达。

暂停、续传与取消

  • 传输支持暂停与续传。
  • 取消上传会清理该次上传在远端产生的部分文件。
  • 已经完成的文件保持原位。
  • 上传前已存在的目标文件不会被删除。

内置网络文件工具

除 SFTP 之外，应用还自带可在同一窗口内运行的文件传输工具：

  • FTP 服务器，支持 PASV 与 EPSV 模式。
  • HTTP/HTTPS 文件服务器，可一键生成自签名证书。
  • TFTP 服务器。
  • FTP 客户端，支持无 TLS、显式 TLS 和隐式 TLS。
  • TFTP 客户端。
