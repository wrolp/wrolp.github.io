用户手册/第 9 章

范围与主机

该面板一次管理一个仓库，主机跟随聚焦的终端：远程仓库通过 SSH exec 通道运行，本地仓库则 直接在本机启动。

  • 远程命令被包装为 env LC_ALL=C GIT_TERMINAL_PROMPT=0 … bash -lc。
  • 本地命令以 HideConsole 启动。
  • 所有操作都调用真实的 git CLI，而不是重新实现 Git 的内部逻辑。

读取与审阅

  • 来自 porcelain v2 的状态。
  • 上限为 2 MB 的逐行 diff。
  • 带 commit-graph 泳道的分页历史。
  • Blame。
  • 冲突三方视图，并支持中止操作。

修改仓库

  • 分支与远程管理。
  • 暂存、取消暂存与丢弃。
  • 提交与 amend。
  • fetch、pull 和 push。
  • Stash。
  • 带进度的 clone。
  • 仓库扫描与 git init。

内置保护措施

  • pull 始终使用 --ff-only。
  • 强制推送仅以 --force-with-lease 的形式提供，并且需要二次确认。
  • 冲突支持三方查看与中止；强制推送前的确认框会说明目标远端与分支。
  • 路径参数绝不会拼接进 shell 命令。后端会拒绝绝对路径、盘符、反斜杠和 ..。
  • “本地忽略”只写入 .git/info/exclude，绝不写入被跟踪的 .gitignore。
