创建连接

SSH 会话

  • 传输：在 Rust 侧用 russh 实现；不需要外部 ssh 命令或 OpenSSH 二进制。
  • 认证：密码或 SSH 密钥。
  • 终端：xterm.js 渲染，xterm-256color PTY，窗口尺寸同步。
  • 保活：可配置的间隔与重试次数。
  • 重连：重连操作复用同一个标签实例；单调递增的 session_id 可防止残留的后台任务污染新会话。

连接健康状态

每个标签显示一个状态点，由三个后端事件驱动：

  • connection-ok —— 已连接；状态点为绿色。
  • connection-suspect —— 保活失败暗示存在问题；状态点变为黄色。
  • connection-closed —— 会话已结束；状态点变为红色。

请使用重连操作复用该标签，而不是打开新标签。

Telnet、串口与本地会话

  • Telnet：纯 TCP，内置 IAC 协商状态机（ECHO、SGA、TERMINAL-TYPE、NAWS）。 自动登录可选且默认关闭，因为该协议是明文传输。
  • 串口（COM）：端口枚举，带 USB 设备友好名称与 VID:PID，以及可配置的 波特率、数据位、停止位、校验位和流控。波特率自动检测会逐个尝试各速率，并按输出看起来像终端文本的程度对结果排序。
  • 本地终端：本地 shell 可以作为顶层标签打开，也可以作为分栏与远程标签并排。
