常见情形

症状已确认的行为应检查的内容
标签页圆点为黄色 connection-suspect：keepalive 报告异常 网络路径与 keepalive 间隔/重试设置；重新连接该标签页
标签页圆点为红色 connection-closed：会话已结束 重新连接会复用该标签页；会分配新的 session_id
本地未列出任何容器 probe_local_docker 先尝试 docker，再尝试 podman，并将“未安装”与“守护进程未运行”区分开 在改动任何内容之前，先确认探测报告的是这两种状态中的哪一种
远程 Git 命令挂起 远程 Git 以 GIT_TERMINAL_PROMPT=0 运行，因此不可能出现交互式提示 确保非交互式 shell 已经能获得凭据
录制缺失 录制默认关闭；WROLP_RECORDING=1 可强制开启 检查设置与环境变量，然后在 recordings/ 下查找
迁移数据后 AI 密钥失效 vault.key 与机器绑定，只有显式迁移才会随之移动 带保险库密钥重新执行迁移，或重新输入 API 密钥
无法分配某个快捷键 Tab、Enter、Ctrl+C/V/X/Z/D/W 为保留键 选择其他组合
面板中 Git 状态未知 状态来自 porcelain v2，且 diff 上限为 2 MB 超大的变更集会被按设计截断
更新程序不工作 它使用 GitHub Release 端点，并且需要在 tauri.conf.json 中配置真实的 pubkey 先配置密钥，再期待更新生效

平台与打包问题

  • 没有 Linux 或 macOS 安装包；请按第 1 章从源码构建。
  • Linux 构建需要该章列出的 Debian/Ubuntu 软件包。
  • 不存在 .github/workflows/，因此没有可确认的自动化构建可供与本地构建 对照。

数据库大小

录制以文件形式存放，SQLite 仅存储其索引，因此 wrolp.db 不应随 录制长度增长。如果它因其他原因变大，设置会显示可回收空间并提供 立即压缩（VACUUM）。

无法从文档中诊断的内容

未确认。源材料未描述日志文件位置、诊断包、 崩溃报告处理、安全模式开关或受支持的重置流程。这些内容被略去，而非猜测。

报告问题

仓库为缺陷报告与功能请求提供 issue 模板（.github/ISSUE_TEMPLATE/）， 并提供 pull request 模板。它没有 CONTRIBUTING.md、行为准则或路线图文档，因此除这些模板之外， 没有文档记载的支持渠道。
