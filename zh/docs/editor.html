用户手册/第 5 章

使用 Monaco 编辑

  • 编辑器是内嵌的 Monaco 编辑器。
  • 它可以在分栏或浮动窗口中打开，并像其他面板一样按会话隔离。
  • 文本编码使用 encoding_rs 自动检测 UTF-8 与 GBK。
  • 可以从远程文件树打开编辑器，与终端标签并排。
未确认。 保存行为（自动保存、原子写入、外部变更检测）、最大文件大小、 行尾符处理、备份文件和编辑器偏好设置，README、发布说明或配置文件中均未描述。

二进制文件与图片

  • 二进制文件以十六进制转储打开。
  • 图片按其 MIME 类型内联预览。

这些视图偏向只读；文档没有描述编辑或保存二进制内容的能力。

语言支持

Monaco 初始化与自定义语言定义位于 src/editor/，包括 shell 语法。README 并未逐一列出所有支持的语言，请查阅该目录以确认你所运行构建中的确切集合。
