用户手册/第 7 章

两类主机

Docker 命令通过 DockerHostRef 定位，它可以指向：

  • 一个 SSH 会话跳板主机 —— 通过在会话的 exec 通道上运行 docker exec 访问容器。
  • 本地守护进程 —— 直接启动 CLI，从而避免引号转义问题。

本地探测（probe_local_docker）先尝试 docker，再尝试 podman，并 区分“未安装”与“已安装但守护进程未运行”。在诊断容器列表为空的原因时，这一区分很重要。

容器操作

  • 列出容器，并创建、删除、启动和停止容器。
  • 一次性日志与流式日志。
  • 三层分析报告。
  • 浏览容器内文件。
  • 在容器内打开 shell。

主机分析

analyze_host 对服务器执行只读检查：操作系统、内核、架构、 已安装的软件包与已安装的工具。command_help 用于查询命令帮助。

只读操作与变更操作

只有分析命令被描述为只读。容器启动/停止/删除和 shell 访问属于变更 操作；文档没有描述针对它们的确认步骤，这一点与 Kubernetes 资源删除不同， 后者确实有应用内确认。
