下载与安装

快速开始

安装或构建 Wrolp Terminal v0.0.12，以开发模式运行，并生成发布包。

下载与支持的平台

当前版本为 v0.0.12（2026-11-07 发布，非预发布版）。发布包 仅提供 MSI：tauri.conf.json 中的打包目标为 ["msi"]。

包平台说明
MSI 安装程序Windows（主要目标）发布流程唯一发布的包
—Linux / macOS不发布安装程序；请从源码构建（见下文）

安装包发布在仓库的 GitHub Releases 页面： github.com/wrolp/wrolp/releases。

版本说明。 v0.0.12 被标记为正常发布版。仓库的 README 明确说明描述的是当前代码状态， 并且“不是路线图”；没有可供查阅的路线图文档。

系统要求

  • Windows 是主要目标；项目也可以在 Linux 与 macOS 上运行和开发。
  • 根据 README，macOS 与 Windows 不需要额外的系统依赖。
  • 在 Debian/Ubuntu 上构建需要下列软件包。
  • 需要 Rust（通过 rustup 安装），且仓库提交了 yarn.lock，因此推荐使用 yarn 作为包管理器。
未确认。 源材料未说明最低操作系统版本、所需的 Node.js 版本、 内存/磁盘要求，也没有说明 WebView2 运行时要求。因此这些数值被省略，而不是猜测。

Linux 构建依赖（Debian/Ubuntu）

sudo apt-get install -y pkg-config libdbus-1-dev libssl-dev libgtk-3-dev \
  libjavascriptcoregtk-4.1-dev libsoup-3.0-dev libwebkit2gtk-4.1-dev

Rust 与前端依赖

curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
yarn

以开发模式运行

yarn tauri dev      # 完整栈（Tauri 会自动启动 Vite 开发服务器）
yarn dev            # 仅前端，用于纯 UI 调试（不涉及 Rust/SSH）

yarn dev 只运行 React 前端，因此在该模式下 SSH、SFTP 以及所有依赖 Rust 的面板都不可用。

构建

yarn build:clean    # 先清理独立的 target 目录再构建
yarn tauri build    # 增量开发构建
命令输出位置
yarn build:cleansrc-tauri/target-release/release/bundle/
yarn tauri buildsrc-tauri/target/

测试

cd src-tauri && cargo check && cargo clippy && cargo test
cd src-tauri && cargo run --bin ssh_test   # 独立的 russh 连接探测
npx playwright install && yarn test:e2e    # Playwright 前端 E2E；后端通过 window.__TAURI_INTERNALS__ 打桩，因此无需构建 Rust

Playwright 测试套件在 e2e/ui/ 下包含约 100 个用例。仓库中不存在 .github/workflows/ 目录，因此项目的自动化构建/测试流水线无法确认。

发布版本

gh auth login -h github.com
yarn run publish    # 先构建，再上传到 GitHub Release；RELEASE_SKIP_CLEAN=1 会复用已有产物

发布使用 GitHub CLI。应用中的更新器指向 GitHub Release 端点，并需要 tauri.conf.json 中真实的 pubkey；若缺少它，对于你自己的构建， 自动更新器不能被视为已配置。
