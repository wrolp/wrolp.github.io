Download & setup

Getting started

Install or build Wrolp Terminal v0.0.12, run it in development, and produce release packages.

Download and supported platforms

The current release is v0.0.12 (released 2026-11-07, not a pre-release). Release packages are MSI only: the bundle target in tauri.conf.json is ["msi"].

PackagePlatformNotes
MSI installerWindows (primary target)The only package published by the release process
—Linux / macOSNo installer is published; build from source (below)

Installers are published on the repository's GitHub Releases page: github.com/wrolp/wrolp/releases.

Version notes. v0.0.12 is marked as a normal release. The repository's README explicitly describes the current code state and is “not a roadmap”; there is no roadmap document to consult.

System requirements

  • Windows is the primary target; the project can also run and be developed on Linux and macOS.
  • No extra system dependencies are needed on macOS and Windows according to the README.
  • Building on Debian/Ubuntu requires the packages listed below.
  • Rust is required (installed through rustup), and the repository commits a yarn.lock, so yarn is the recommended package manager.
Not confirmed. The source material does not state minimum OS versions, a required Node.js version, RAM/disk requirements, or a WebView2 runtime requirement. Those values are therefore omitted rather than guessed.

Linux build dependencies (Debian/Ubuntu)

sudo apt-get install -y pkg-config libdbus-1-dev libssl-dev libgtk-3-dev \
  libjavascriptcoregtk-4.1-dev libsoup-3.0-dev libwebkit2gtk-4.1-dev

Rust and frontend dependencies

curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
yarn

Run in development

yarn tauri dev      # full stack (Tauri starts the Vite dev server automatically)
yarn dev            # frontend only, for pure UI debugging (no Rust/SSH)

yarn dev serves the React frontend alone, so SSH, SFTP and every Rust-backed panel are unavailable in that mode.

Build

yarn build:clean    # build after clearing the separate target directory
yarn tauri build    # incremental development build
CommandOutput location
yarn build:cleansrc-tauri/target-release/release/bundle/
yarn tauri buildsrc-tauri/target/

Test

cd src-tauri && cargo check && cargo clippy && cargo test
cd src-tauri && cargo run --bin ssh_test   # a standalone russh connectivity probe
npx playwright install && yarn test:e2e    # Playwright frontend E2E; the backend is stubbed via window.__TAURI_INTERNALS__, so no Rust build is needed

The Playwright suite contains about 100 specs under e2e/ui/. There is no .github/workflows/ directory in the repository, so the project's automated build/test pipeline cannot be confirmed.

Publish a release

gh auth login -h github.com
yarn run publish    # build first, then upload to a GitHub Release; RELEASE_SKIP_CLEAN=1 reuses existing artifacts

Publishing uses the GitHub CLI. The updater in the application points at a GitHub Release endpoint and requires a real pubkey in tauri.conf.json; without it the auto-updater cannot be considered configured for your own builds.
