User manual/Chapter 5

Editing with Monaco

  • The editor is an embedded Monaco editor.
  • It opens either in a split pane or in a floating window, and is isolated per session like other panes.
  • Text encoding is detected automatically with encoding_rs; a non-UTF-8 file is marked with its encoding in the tab and saved in that encoding.
  • The editor bar switches encoding (UTF-8, GBK, GB18030, Big5, Shift-JIS, EUC-KR, ISO-8859-1, Windows-1252) and line endings (LF / CRLF).
  • Ctrl+S saves; closing a modified editor asks whether to save and close or discard the changes.
  • Editors can be opened from the remote file tree alongside terminal tabs.

Binary files and images

  • Binary files open as a hex dump.
  • Images are previewed inline according to their MIME type.

The hex view is read-only and says so in the page; image preview is display-only. Neither edits or saves binary content.

Language support

The toolbar sets syntax highlighting manually from an alphabetically sorted list: plain text, JavaScript, TypeScript, JSON, HTML, CSS, SCSS, Less, XML, Markdown, Python, Rust, Go, Java, C, C++, C#, PHP, Ruby, Shell, YAML, INI/TOML, SQL, Dockerfile, Lua, Makefile, Nginx config and Properties/.env.
