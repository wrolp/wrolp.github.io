User manual/Chapter 5

Editing with Monaco

  • The editor is an embedded Monaco editor.
  • It opens either in a split pane or in a floating window, and is isolated per session like other panes.
  • Text encoding is detected automatically for UTF-8 and GBK using encoding_rs.
  • Editors can be opened from the remote file tree alongside terminal tabs.
Not confirmed. Save behaviour (auto-save, atomic write, external-change detection), maximum file size, line-ending handling, backup files and editor preference controls are not described in the README, release notes or configuration files.

Binary files and images

  • Binary files open as a hex dump.
  • Images are previewed inline according to their MIME type.

These views are read-oriented; the documentation does not describe editing or saving binary content.

Language support

Monaco initialisation and custom language definitions live in src/editor/, including shell syntax. The README does not enumerate every supported language, so consult that directory for the exact set in your build.
