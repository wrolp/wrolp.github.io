User manual/Chapter 8

Which cluster you are looking at

Kubernetes mode follows the currently focused terminal to choose its host: either an SSH jump host or the local kubeconfig. Switching focus therefore switches the cluster context source, which is why the panel and the terminal should be read together.

Contexts and namespaces

  • Context and namespace selectors, plus a search box.
  • The default namespace filter is All namespaces.
  • Namespace labels are coloured by name with a stable mapping, so the same namespace keeps its colour.

Resource kinds

Ten kinds share one row model: pods, deployments, statefulsets, daemonsets, services, ingresses, jobs, cronjobs, configmaps and secrets.
