This manual covers Wrolp Terminal v0.0.12, chapter by chapter: installation, connections and session layout, files, operations panels, the AI assistant and data management.

How to read it. Each chapter starts with the entry point and the steps, then explains interface behaviour, defaults and limits. Commands, paths and field names use a monospace font so you can match them to the application.

Things to know

  • Release packages are Windows MSI only; Linux and macOS build from source.
  • Connection profiles and AI keys are encrypted; decryption depends on vault.key in the data directory, so back it up with the rest.
  • Session recording is off by default; once enabled, events are written to the local SQLite database and never uploaded.
  • Tunnels are local port forwards: a listening port on your machine relays traffic through the SSH session to a remote target.
  • Docker, Kubernetes and Git panels run their commands on the host of the focused terminal.
