This manual documents Wrolp Terminal v0.0.12 as described by the repository's README, release notes, package.json, src-tauri/Cargo.toml, configuration files and source layout (retrieved 2026-11-07).

How to read it. Each chapter separates what the source material confirms from what it does not. Where a dialog, menu path, field name, default value or screenshot is not documented, the chapter says so explicitly under “Not confirmed” instead of inventing a procedure. No screenshots are reproduced because none are available in the source material.

  • When something breaks: jump to 13; each symptom links back to the relevant chapter.

Coverage and source limits

  • Release packages are MSI only; Linux/macOS must build from source.
  • No CONTRIBUTING.md, code of conduct or development-process document exists. The repository provides issue templates (bug report and feature request) and a pull request template.
  • No roadmap document: the README states that it describes the current code, not future plans.
  • No CI configuration (.github/workflows/ is absent), so automated checks cannot be confirmed.
  • UI entry points and parameter defaults that are not present in the README, release notes, configuration or source layout remain marked as unconfirmed in the relevant chapter.
